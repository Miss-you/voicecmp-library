# voicecmp-library

视频文字整理项目的公开目录。当前阶段只公开本说明、来源目录和发布规则，**没有公开任何阅读稿、逐字稿、字幕、原始转写、音视频或模型**。

- [来源目录](CATALOG.md)
- [机器可读目录](catalog.json)
- [内容发布规则](CONTENT_POLICY.md)

目录用于指向原始作者与原始视频，不代表作者认可本项目，也不表示已取得全文转载许可。文字处理工具与未公开文稿另行管理。

所有条目目前均为 `text_published: false`。来源标题和频道名称用于标识出处；原内容的权利归相应权利人。公开可观看、非营利和自动转写本身不等同于取得再发布许可。

本仓库使用独立提交历史。自动化只检查公开目录，不会从私有仓库同步文字稿；未来公开正文需要另行明确决定并核实相应许可。
